# User Documentation

Everything an end user or sysop needs to install, configure, and operate **oyk-node**:

- [Getting Started](getting-started.md) — Requirements, building, quick deployment, and platform notes across desktop, embedded, mobile, and retro ports.
- [Configuration Reference](configuration.md) — Single authoritative reference for `node.cfg`, `[logfiles]`, radio interfaces, line-ending behavior, daily log rotation, and `banlist.cfg`.
- [Operator Guide](operator-guide.md) — Local operator UI (`Node` menu, 7-tab Settings, Themes, `Ctrl+A` terminal hotkeys), remote packet commands, and ban appeals.
- [Port Feature Matrix](feature-matrix.md) — Complete capability comparison table across all 14 build targets.
- [UI Gallery](ui-gallery.md) — Automated screenshots across POSIX `ncurses`, X11 `GTK+ 2.0`, Windows, macOS, Android, Teensy 4.1 `TinyTMUX`, Raspberry Pi Pico, MS-DOS Text/Graphical, Classic Macintosh, Apple IIGS GS/OS, Amiga Workbench, and Atari ST GEM.
