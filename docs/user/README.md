# User Documentation

Everything an end user or sysop needs to install, configure, and operate **oyk-node**:

- [Getting Started](getting-started.md) — Requirements, building, quick deployment, and platform notes.
- [Configuration Reference](configuration.md) — Single authoritative reference for `node.cfg`, `[logfiles]`, radio interfaces, line-ending behavior, daily log rotation, and `banlist.cfg`.
- [Operator Guide](operator-guide.md) — Using the local operator UI (`Node` menu bar), remote packet commands, and managing bans and appeals.
- [UI Gallery](ui-gallery.md) — Automated screenshots of every tested operator workflow across all five ports (POSIX ncurses, MS-DOS, Teensy 4.1 TinyTMUX, X11 GTK+ 2.0, and Windows).
